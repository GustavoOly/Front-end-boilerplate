## Features

- [x] webpack
- [x] babel
- [x] tailwind and postcss loader
- [x] Prettier: Automatic Class Sorting
- [x] React

## Use

```shell
git clone https://github.com/GustavoOly/Front-end-boilerplate.git
```

```shell
cd Front-end-boilerplate
```

```shell
pnpm install
```

```bash
pnpm dev
```
